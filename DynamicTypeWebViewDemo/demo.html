Dynamic Type × WebView

OSの「設定 → アクセシビリティ → 画面表示とテキストサイズ → さらに大きな文字」でフォントサイズを変更すると、 アプリがリロードを検知してこのページに反映されます。

🔤 WebView の body フォントサイズ（実測値） ---
✅ 対応済み — em 単位で指定
GOOD
お知らせ：新機能がリリースされました

このテキストは em 単位 で指定しています。body の -apple-system-body を起点に、 ダイナミックタイプの変更に連動してスケールします。

GOOD
アクセシビリティ対応のコンテンツ

タイトル: font-size: 1.143em（≈16px）、説明文: font-size: 0.857em（≈12px）。 em により body のサイズ変化に追従します。

❌ 未対応 — px を固定指定
BAD
お知らせ：新機能がリリースされました

このテキストは px 固定（16px / 12px）です。上のセクションと比べてください。 ダイナミックタイプを変更してもサイズが変わりません。

BAD
アクセシビリティに非対応のコンテンツ

文字サイズを大きく設定しているユーザー（約 25〜35%）にとって、 このテキストは読みにくいままです。

実装のポイント（CSS）
/* ① body に -apple-system-body を指定 */
body {
  font: -apple-system-body; /* ✅ iOS Dynamic Type に opt-in */
}

/* ② font-size は em（body 基準の相対値）*/
.title {
  font-size: 1.143em; /* ✅ スケールする */
}
.description {
  font-size: 0.857em; /* ✅ スケールする */
}

/* ❌ px 固定はスケールしない */
.bad-title {
  font-size: 16px; /* ❌ 変化しない */
}
.bad-description {
  font-size: 12px; /* ❌ 変化しない */
}
