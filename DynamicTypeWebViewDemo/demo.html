Dynamic Type × WebView

OSの「設定 → アクセシビリティ → 画面表示とテキストサイズ → さらに大きな文字」でフォントサイズを変更すると、 アプリがリロードを検知してこのページに反映されます。

🔤 body フォントサイズ（em / rem のベース） ---
🌐 html ルートフォントサイズ（rem のベース） ---
✅ 対応済み — em 単位で指定
GOOD
お知らせ：新機能がリリースされました

このテキストは em 単位 で指定しています。body の -apple-system-body を起点に、 ダイナミックタイプの変更に連動してスケールします。

GOOD
アクセシビリティ対応のコンテンツ

タイトル: font-size: 1.143em（≈16px）、説明文: font-size: 0.857em（≈12px）。 em により body のサイズ変化に追従します。

✅ 対応済み — rem + :root 指定
REM
お知らせ：新機能がリリースされました

このテキストは rem 単位 で指定しています。:root { font: -apple-system-body } を追加することで html のサイズも Dynamic Type に追従し、rem もスケールします。

REM
:root に指定するのがポイント

タイトル: font-size: 1.143rem、説明文: font-size: 0.857rem。 上の html ルートフォントサイズが em セクションの body サイズと同じ値になっていれば、 rem が正しく追従している証拠です。

❌ 未対応 — px を固定指定
BAD
お知らせ：新機能がリリースされました

このテキストは px 固定（16px / 12px）です。上のセクションと比べてください。 ダイナミックタイプを変更してもサイズが変わりません。

BAD
アクセシビリティに非対応のコンテンツ

文字サイズを大きく設定しているユーザー（約 25〜35%）にとって、 このテキストは読みにくいままです。

実装のポイント（CSS）
/* ① :root と body の両方に -apple-system-body を指定 */
:root {
  font: -apple-system-body; /* ✅ rem のベース（html）も追従 */
}
body {
  font: -apple-system-body; /* ✅ em のベース（body）も追従 */
}

/* ✅ em — body 基準、Dynamic Type に追従 */
.em-title {
  font-size: 1.143em; /* ✅ スケールする */
}

/* ✅ rem — :root 指定により Dynamic Type に追従 */
.rem-title {
  font-size: 1.143rem; /* ✅ :root 指定でスケールする */
}

/* ❌ px 固定はスケールしない */
.bad-title {
  font-size: 16px; /* ❌ 変化しない */
}
