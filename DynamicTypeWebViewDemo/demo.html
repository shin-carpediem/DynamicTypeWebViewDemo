evaluateJavaScript 方式 × Dynamic Type

Swift 側で body フォントサイズを取得し、evaluateJavaScript で :root の font-size を直接書き換える方式です。 リロード不要で、独自のスケール値も設定できます。

🔤 :root font-size（Swift から JS で注入した値） ---
🔄 Dynamic Type 変更回数（リロードなしで即時反映） ---
動作の仕組み
1
ユーザーが「設定 → アクセシビリティ → さらに大きな文字」を変更する
2
Swift 側で UIContentSizeCategory.didChangeNotification を受信する
3
UIFont.preferredFont(forTextStyle: .body).pointSize で現在のサイズを取得する
4
evaluateJavaScript で document.documentElement.style.fontSize を書き換える
5
rem 指定の要素が :root のサイズを起点にスケールする（リロードなし）
Swift 実装
@objc private func dynamicTypeDidChange() {
    applyFontSize()
}

func webView(_ webView: WKWebView, didFinish navigation: WKNavigation!) {
    applyFontSize() // ページロード完了時にも適用
}

private func applyFontSize() {
    let size = UIFont.preferredFont(forTextStyle: .body).pointSize
    webView?.evaluateJavaScript(
        "document.documentElement.style.fontSize = '\(size)px'",
        completionHandler: nil
    )
}
✅ 対応済み — rem 単位で指定
GOOD
お知らせ：新機能がリリースされました

rem 単位 で指定。Swift が :root の font-size を書き換えるため、 リロードなしでスケールします。タイトル 1.143rem、本文 0.857rem。

GOOD
独自スケールにも対応

Swift 側で注入する値を変えれば、上限キャップや独自の刻み幅など Apple のスケールに縛られない制御が可能です。

❌ 未対応 — px 固定指定
BAD
:root が変わってもスケールしない

px 固定（16px / 12px）のため、Swift が :root を書き換えても このテキストは変化しません。上の rem セクションと比較してください。

参考 — より楽な代替案: font: -apple-system-body + reload()
参考
CSS だけで Dynamic Type に追従させる方法

:root と body に font: -apple-system-body を指定し、 通知受信時に webView.reload() を呼ぶだけで同様の効果が得られます。 実装はシンプルですが、リロードが発生する点と Apple のスケールに固定される点が evaluateJavaScript 方式との違いです。 

/* CSS: -apple-system-body を指定するだけでよい */
:root, body { font: -apple-system-body; }

// Swift: リロードで CSS を再評価させる
@objc private func dynamicTypeDidChange() {
    webView?.reload()
}
